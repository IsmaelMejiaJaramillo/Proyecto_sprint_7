# Anuncios de venta de coches

Aplicación web interactiva para explorar un conjunto de más de 51,000 anuncios de venta de coches usados en Estados Unidos. Sirve para ver cómo se distribuyen los precios y el kilometraje de los vehículos, y cómo se relacionan entre sí.

**Aplicación desplegada:** https://proyecto-sprint-7-21rx.onrender.com

## Funcionalidad

- Muestra métricas rápidas: número de anuncios, precio mediano y odómetro mediano.
- Permite filtrar los anuncios por rango de precio, año del modelo, tipo de vehículo y condición.
- Construye gráficos interactivos al activar las casillas: histograma del odómetro, histograma del precio, gráfico de dispersión de precio contra odómetro y diagrama de cajas del precio por tipo de vehículo.
- Muestra una tabla con los primeros anuncios que cumplen los filtros.
